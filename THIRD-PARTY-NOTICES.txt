量化文件来源 https://huggingface.co/bartowski/Qwen_Qwen3.5-2B-GGUF/commit/0719ef0c2bc06b5da2cccfec9dc26b8328f8afbd
许可链接 https://huggingface.co/Qwen/Qwen3.5-2B/blob/main/LICENSE
基座模型为 Qwen3.5-2B-Base，见 https://huggingface.co/Qwen/Qwen3.5-2B-Base。

若替换为其他模型文件，须重新核对该模型卡许可。

四、非随包组件（用户自行安装或为外部服务）

- Moect 1.2.8（GPL-3.0）是由用户自行安装的独立第三方程序，可导出获授权的微信会话 JSON。
  WxLocal 参照 Moect 源码在本项目中重写，Moect 二进制不随包分发。
  Moect 上游 https://github.com/mofan6/Moect/tree/v1.2.8
  Moect 上游亦署名 WeChatMsg（SiYuan 及贡献者）与 WeChatMsg-4x。见其声明
  https://github.com/mofan6/Moect/blob/v1.2.8/THIRD_PARTY_NOTICES.md
  代码许可证、平台服务条款、第三方程序许可三者不可相互替代。
- DeepSeek / 豆包（火山方舟）API 由用户自行注册并填入 API Key，受各服务商条款约束。
- 微信 / QQ 客户端须由用户自行安装并登录。读取仅限本人授权的会话，受平台规则约束。
  平台规则与本项目许可证分别适用。
- LLamaSharp 的 Windows CPU 后端调用 Microsoft Visual C++ v14 x64 运行库（含 VCOMP140.dll）。
  如系统缺少该运行库，用户可从 Microsoft 自行安装。该独立安装程序不随包分发。
  https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist
