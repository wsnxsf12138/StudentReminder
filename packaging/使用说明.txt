AI 学生事务助理 — 同学试用说明

1. 运行
   需要 Windows 10/11 x64。压缩包为自包含发布，无需另外安装 .NET。
   将 ZIP 完整解压到普通文件夹，再双击 StudentReminder.App.exe。

2. 数据位置
   每个解压位置使用 %LOCALAPPDATA%\StudentReminder-Trial 下的独立目录。
   双击启动时，新解压位置从空库开始。主窗口会显示实际路径。
   messages.db、日志和 DPAPI 加密凭据保存在该本机目录，删除程序目录后仍保留。
   「设置 → 隐私与数据」可暂停同步和分析并清除微信、QQ 直读缓存，已入库的消息和事项仍保留。

3. 首次使用
   来源同步和云端分析启动时默认暂停。仅在界面选择有权处理的会话后，按需分别开启。
   云端分析需要在「AI 分析 → 模型设置」填写自己的 DeepSeek 或豆包 API Key。

4. 本地初筛
   将 GGUF 放在 EXE 同级的 Models 目录可自动识别，也可在「AI 分析 → 本地初筛」选择文件。
   无模型时可使用云端分析。若本地初筛提示缺少 MSVCP140.dll、VCRUNTIME140.dll 或 VCOMP140.dll，
   可从 Microsoft 安装 Visual C++ v14 x64 运行库，链接见 THIRD-PARTY-NOTICES.txt。

5. 备份与卸载
   先退出程序（包括托盘中的实例），备份整个数据目录，再删除程序目录。
   如已启用登录 Windows 后启动，可先在设置中关闭。请勿手工删除微信或 QQ 目录。

6. 使用边界
   仅处理本人有权处理的会话。请勿共用账号，也不要将 messages.db 或数据目录发给他人。

7. 试用范围
   这是 Alpha 试用版。提交问题时请使用合成样本，避免上传私人数据。
