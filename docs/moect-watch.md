# Moect 备用导入

1. 在 Moect 刷新目标账号的聊天快照，将一个获授权群的近期文字快速导出为 JSON。后续沿用同一导出根目录，时间范围可少量重叠。 [Moect 使用指南](https://github.com/mofan6/Moect/blob/v1.2.8/docs/usage.md)
2. 在助理主窗口打开「Moect 备用导入」。选择导出根目录，再选择该群的一份 JSON 样本。助理记住样本里的会话 ID。已用脚本导入过同一账号时，填写当时的账号别名以继续去重。
3. 「检查间隔」默认 30 分钟，支持 1～1440 分钟。点「开始定时导入」立即处理一次，之后按所选间隔检查文件。也可以只点「立即检查」。设置在处理时保存，暂停后可修改。窗口可最小化，关闭时停止检查。
4. 导入的数据保存在本机。要分析时，打开「AI 分析 → 历史消息」，选择 Moect 会话、日期，预览脱敏正文后勾选并提交。待确认事项统一在「事项」审核。0.2.4-alpha 生成的旧结果仍可在「旧版 Moect 分析结果」查看。

导出文件指纹与消息同事务保存，重复扫描或导出区间重叠时会去重。导出文件保存在 Moect 选择的目录，SQLite 和加密凭据在助理的数据目录。

助理的定时器从已经生成的 JSON 开始工作。实时采集请使用 WxLocal。 [AI 分析与事项审核](../README.md#ai-分析与事项审核)
