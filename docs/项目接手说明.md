# AI 学生事务助理｜项目接手说明

给第一次接手本仓库的 AI 和开发者。项目是一个面向高校学生的 Windows 桌面助理。它把用户选定的微信、QQ 会话或手动导入的消息存入本机，提取带来源证据的事项候选，由用户审核后保存为可追溯的事件。技术栈是 C#、.NET 10、WPF、SQLite。

## 接手先看

1. 用 `git status --short --branch` 和 `git log -1 --oneline --decorate` 确认当前工作区和版本。按 [AGENTS.md](../AGENTS.md) 的约定保留其他人在做的改动，只执行本次指定的任务。
2. 从 [README](../README.md) 找到启动和操作步骤，从 [版本交接索引](handoffs/README.md) 找到当前版本的实际验收证据。
3. 按任务 ID 读 [任务计划书 §9](AI学生事务助理_任务计划书_Codex版.md#9-详细任务分解可交给-codex) 及相关 ADR。计划书用于查需求和验收标准，版本交接用于查实现和验证结果。早期文档中的 WeFlow、Moect、qqflow-server 选型记录了当时的路线。

## 本机使用与验证

在 Windows PowerShell 的仓库根目录运行。SDK 以 [global.json](../global.json) 为准，允许同一 .NET 10 系列较新的 feature band。构建前关闭占用输出目录的应用实例。

```powershell
./scripts/Test-Project.ps1
dotnet run --project src/StudentReminder.App --configuration Release --no-build -- --data-dir "$env:TEMP\StudentReminder-handoff"
```

- **快速验收**：在隔离目录启动后查看首页「事项日历」，再切到「消息导入」点击「导入合成样本」并重试一次，核对 [README 的预期计数](../README.md#构建与运行)。适配器契约通过本地合成测试验证。测试代码在 [tests/StudentReminder.Tests](../tests/StudentReminder.Tests)，合成样本在 [tests/Fixtures](../tests/Fixtures)。
- **真实会话**：保持对应客户端登录。在「消息来源」分别建立 WxLocal 和 QqLocal 配置，填写自定别名，再点「读取会话」。各自勾选并保存获授权的会话后，可分别启动后台同步。首次可先「同步一次」核对入库。切换同平台账号时先暂停，并为新账号使用新别名。
- **AI 分析**：来源同步和云分析分别授权，启动应用时默认暂停。自动分析只处理开启后发送且经直读新入库的授权消息。首次回溯或旧消息走「历史消息」预览后手动提交。云端收到脱敏文本、发送时间和时区。模型结果由用户在「事项」确认，已确认事件支持离线查看和修改。

## 数据、版本与交付

- 默认应用数据在 `%LOCALAPPDATA%\StudentReminder`，含 `messages.db`、日志及 DPAPI 加密凭据。调试时 `--data-dir` 隔离应用数据库、日志和凭据。直读缓存仍由 WxLocal／QqLocal 各自管理，位于默认本机目录的 `wxlocal\` 和 `qqlocal\` 下。
- 直读缓存按聊天明文保护。验证用合成样本，避免把真实聊天、缓存库、日志、账号标识和凭据写入提交或交接。真实链路验收分别记录已完成的步骤和证据范围。
- 从 v6 升到 v7 前备份应用数据目录。旧版会拒绝较新 schema，回退程序时恢复升级前的备份。新增迁移要附升级测试，发布过的迁移保持原样。
- 每完成一个版本，按 [交接模板](handoffs/TEMPLATE.md) 新建独立文档，同步更新版本号、CHANGELOG 和索引，验收后打标签。按用户授权决定推送。最近公开发行版用 `git show v0.6.8-alpha` 定位。

## 接手时可用的技能

- `diagnosing-bugs` 适合来源发现、授权、增量入库或 AI 分析故障。优先用合成测试或已有探针建立复现。
- `implement` 适合按任务 ID 实现已确定范围，`review` 适合做提交前的规格与标准检查。
- `computer-use` 适合在隔离数据目录验证 WPF 的实际操作。
