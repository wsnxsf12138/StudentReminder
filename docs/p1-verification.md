## 桌面交互验收

通过 computer-use 在实际 WPF 窗口操作：

1. 首启显示本地模式和 0 条消息，没有网络采集状态承诺。
2. 点击合成样本，显示 117 条及预期导入计数。
3. 再次点击，显示重复 128、新增 0，总数不变。
4. 粘贴两行合成消息并保存，新增 1，总数 118。
5. 选择该消息，证据区显示原始换行、manual/paste、账号别名、会话及带时区时间。
6. 关闭并重新启动新版应用，仍显示完整的 118 条合成记录。
7. 通过原生文件选择器选择冲突 JSON 文件，导入完成显示新增 1、冲突 1，总数变为 119。

JSON 文件选择器已完成端到端桌面验收：通过截图坐标聚焦文件名，再输入合成文件路径并点击打开。文件读取、BOM、大小限制和入库同时由集成测试覆盖。

桌面测试最终保存的 119 条全部为合成消息（主样本 117、粘贴 1、冲突证据 1），只保存在本地演示数据库。数据库本身未加密；本轮不建议放入不必要的敏感信息。
