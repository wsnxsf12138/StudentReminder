# 0.6.9-alpha 版本交接

## 版本定位与目标

- 完成日期为 2026-11-14。范围为 P4-02、P4-04、P4-05 的桌面图标接入。
- 代码验收提交为私有仓 `c105b5f`、公开仓独立克隆 `498365e`（`codex/icon-integration`）。两仓各自提交本交接文档。本次采用本地 Git 提交交付。
- EXE、窗口和任务栏使用多尺寸日历气泡图标。托盘按微信和 QQ 的启用状态与健康记录切换图标，双击优先打开本次运行中待查看的错过提醒，其次打开异常来源。界面图标搭配原有状态文字。
- SVG 母版和 ICO 随源码保存，界面使用从 SVG 转换的 WPF 矢量资源。出包脚本按路径放行这套资源。

## 使用与复现

- 使用 Windows 10/11 与 .NET 10 SDK。在仓库根目录运行 `./scripts/Test-Project.ps1`。
- 验证实例可使用 `dotnet run --project src/StudentReminder.App -c Release --no-build -- --data-dir "$env:TEMP\StudentReminder-icons-069"`。
- 在「消息来源」查看两路状态，在「事项」查看待确认和已完成图标，在「今日」查看未来 72 小时截止和错过的提醒。托盘按现有 5 秒检查周期更新，提示文字分别显示微信和 QQ 的状态。

## 数据与兼容

- 常规数据仍位于 `%LOCALAPPDATA%\StudentReminder`。试用版沿用按解压位置划分的数据目录。验收使用独立目录和合成数据。
- SQLite schema 仍为 v8，无迁移。回退时先退出程序并备份整个数据目录，再换回同为 schema v8 的 0.6.8-alpha。
