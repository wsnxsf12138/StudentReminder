## 使用与复现

- Windows 10/11、.NET 10、WPF、SQLite。验收使用 .NET SDK 10.0.403。NuGet 锁文件无变化。
- 运行 `./scripts/Test-Project.ps1` 完成锁定还原、Release 构建和测试。用 `dotnet run --project src/StudentReminder.App --configuration Release --no-build` 启动。合成验收可追加 `-- --data-dir "$env:TEMP\StudentReminder-p3"`。
- 在「消息来源」保存 WxLocal 配置、选择获授权的会话、启动后台同步。在「AI 分析」配置 DeepSeek 或豆包，可先用固定合成文本测试连接。再次勾选要分析的会话后开启自动分析。
- 历史或首次回溯消息在「历史消息」按会话和日期预览后手动提交。Moect 保留备用导入及旧结果查看，手动分析同样从统一入口发起。「事项」提供证据、编辑确认、关联已有事件及版本查看。 [完整运行步骤](../../README.md#ai-分析与事项审核)

## 数据与兼容

- 默认应用数据目录为 `%LOCALAPPDATA%\StudentReminder`。SQLite 存储在 `messages.db`，凭据由当前 Windows 用户的 DPAPI 加密后写入 `secrets/`。出站正文按规则脱敏，包含消息发送时间和时区。日志和交接记录只保留运行信息。
- SQLite schema 从 v4 升至 v5。迁移允许 WxLocal 配置使用端口 0，加入 WxLocal 入库时间、分析状态、请求用量及退避、候选证据和事件版本。升级测试保留旧来源配置、消息和 Moect 结果。
- 升级前关闭应用，备份整个数据目录。回退时关闭应用，使用旧版程序并恢复升级前备份。升级后产生的事项和版本保存在 v5 数据目录中，回退前可另存该目录。

## 已知问题与下一步

- 自动分析按当次开启时间划分范围。暂停或关闭期间的消息可从历史补分析。轻筛存在漏项的可能，筛过的消息也可手动选择。
