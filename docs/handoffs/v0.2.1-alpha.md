# v0.2.1-alpha 版本交接

## 版本定位与目标

- 日期 2026-11-11，代码和文档以 `v0.2.1-alpha` 标签定位。
- 范围为 P0-02、P0-03 和 P2-01～02 的候选核对。WeMemory 授权费用导致改用 Moect 单群文件导入，并验证 WeFlow Rust CLI 的本机接口。
- Moect 演示导出、转换、入库和重放已通过。Rust API 的启动和鉴权已通过，真实账号数据源的 P0/P2 验收仍待完成。

## 使用与复现

- Windows x64、.NET 10。转换脚本使用 PowerShell 7.5 或更新版本。程序版本固定为 Moect 1.2.8 和 WeFlow Rust CLI 6.0.0，程序包、EXE 和来源提交见服务清单。
- `./scripts/Install-ProjectServices.ps1 -Service moect` 安装，`./scripts/Start-ProjectService.ps1 -Service moect` 启动。选单群、时间范围、JSON 和快速导出，再运行 `./scripts/Convert-MoectExport.ps1`。转换参数与文件位置见 [微信候选 PoC](../poc-wechat-alternatives.md)。
- `./scripts/Test-Project.ps1` 执行锁定还原、Release 构建和测试。来源探测工具的复测命令见 [WeMemory PoC](../poc-wememory.md)。

## 数据与兼容

- Moect 连接账号时在本机保存账号级快照。群导出与转换输出应保存在 `artifacts/` 下，真实记录、凭据与运行文件不进入 Git。
- 项目继续使用 schema v2。导入使用已有事务和去重逻辑，按本地账号别名、会话、上游编号或指纹识别消息。
- 可通过 `v0.2.0-alpha` 回退代码。回退前关闭应用并备份数据目录。两个版本均使用 schema v2，文件导入形成的本地证据随数据库保留。

## 验收证据

- 锁定还原、Release 构建和本地回归通过，共 56 项测试，构建零警告零错误。
- Moect 演示群导出 9 条，转换 8 条文字。导入新增 8 条，重放新增 0 条并识别 8 条重复，隔离库最终 8 条。指定另一群名时转换拒绝。
- Rust CLI 6.0.0 通过包校验和构建来源证明。服务在 `127.0.0.1:18108` 返回 API v2，无 Token 的 OpenAPI 请求返回 401，带 Token 可读契约，空配置读会话返回 409。探测结束后关闭临时服务。
- 本版 CI 尚未运行。v0.2.0-alpha 的历史 CI 见其交接。

## 已知问题与下一步

- Moect 真实账号及当前微信 4.2.0.13 的目标群读取待实测。若继续采用 Moect，先由用户确认账号级本地快照，再按指定群导出。
