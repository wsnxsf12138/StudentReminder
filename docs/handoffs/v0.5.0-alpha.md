# 0.5.0-alpha 版本交接

## 版本定位与目标

- 完成日期为 2026-11-12。代码验收提交为 `81c28d8`，完整版本快照由 `v0.5.0-alpha` 标签定位。
- P4-01～P4-05 交付本地事项提醒、错过提醒补报、离线每日摘要、手动 AI 润色、「今日」与证据导航、托盘运行、暂停采集及可选的 Windows 登录启动。
- 按本轮要求退役 qqflow-server、WeFlow 桌面版、WeFlow CLI 和 WeMemory。应用来源只保留 WxLocal 和 QqLocal 直读，另可用 Moect 备用导入及手动导入。旧标签保留旧版本的运行和实验记录。

## 使用与复现

- Windows 10/11、.NET 10 SDK、WPF。运行 `./scripts/Test-Project.ps1`，再用 `dotnet run --project src/StudentReminder.App --configuration Release --no-build -- --data-dir "$env:TEMP\StudentReminder-P4-demo"` 启动隔离实例。
- 在「事项」确认含明确时间的候选。开始和截止默认各提前 1 天、2 小时提醒。「设置」可修改提前分钟数，留空可关闭对应规则。电脑唤醒或程序重启后，「今日 → 错过的提醒」会显示错过计划的原定时间和状态。
- 「今日」默认在本地时间 07:30 生成摘要，支持手动刷新及跳转到事项、候选和证据。需要润色时，选择已有配置的 DeepSeek 或豆包，检查预览后确认发送。定时摘要离线运行。
- 最小化进入托盘，主窗口默认关闭即退出。「设置」可开启关闭后驻留和登录启动。登录启动仅在默认数据目录可用，采集和自动分析仍默认为暂停。托盘「暂停采集」停止直读同步、Moect 定时导入及在途分析。

## 数据与兼容

- 默认数据目录为 `%LOCALAPPDATA%\StudentReminder`。使用 `--data-dir` 隔离应用数据库、日志与 DPAPI 凭据。云润色沿用现有模型配置和请求预算，仅提交预览中列出的脱敏事项字段。
- 启动前退出旧版本并备份整个应用数据目录。schema v6→v7 在事务内初始化提醒和摘要状态，为旧版已确认事项补排未来提醒。迁移清除已退役来源的采集配置、会话授权选择、游标及上次成功时间，保留已入库消息、事项、证据和版本。
- 需要回退时退出 0.5.0-alpha，若曾在设置中启用 Windows 登录启动，先关闭该选项。恢复升级前的数据目录备份后再运行 0.4.2-alpha。旧版拒绝打开 schema v7，备份恢复会回到备份时的数据状态。
- 此机器的四个已退役安装目录及其项目内安装包已移到 本机独立归档目录。项目内 Moect 1.2.8 可执行文件的哈希与清单一致。
