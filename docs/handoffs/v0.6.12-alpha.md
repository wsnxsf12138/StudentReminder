# 0.6.12-alpha 版本交接

## 版本定位与目标

- 完成日期为 2026-11-14。任务范围为 P4-04 的首页问候和选中日期的日程。
- 月历上方按本机时段显示问候和当天日期。右侧常驻选中日期的计划与事项，两栏之间可左右拖动调整宽度，新窗口使用默认比例。月历根据宽度实时切换每行 7、5 或 4 个日期，窄布局在日期格内标出星期，可纵向滚动。
- 点击日期后右侧清单即时更新。点击事项标题可进详情和来源证据。只知道日期的计划继续显示「时间待定」。
- 本地标签为 `v0.6.12-alpha`。代码验收提交为 `275339c`（`codex/calendar-agenda-0.6.12`）。分支基于本仓的 `v0.6.11-alpha`，远端默认分支仍为 `fd891f2`。

## 使用与复现

- 在 Windows 与 .NET 10 SDK 下运行 `./scripts/Test-Project.ps1`。用 `dotnet run --project src/StudentReminder.App -c Release --no-build -- --data-dir "$env:TEMP\StudentReminder-calendar-agenda"` 启动隔离实例。
- 在「事项日历」点击不同日期并拖动中间分隔线。日期格支持方向键换日，上下键移动一行，Enter 或空格可将焦点移到有事项的清单。分隔线获得焦点时可用左右方向键调整。
- 列表仅展示已有的已确认事项。使用合成事项分别核对有安排和空日期。

## 数据与兼容

- 常规数据位于 `%LOCALAPPDATA%\StudentReminder`，试用版按解压位置使用 `%LOCALAPPDATA%\StudentReminder-Trial` 下的隔离目录。桌面核对使用 `--data-dir` 和合成数据。
- 数据库沿用 SQLite schema v8，本版无迁移。回退前退出应用并备份数据目录，再换回同为 v8 的 `0.6.11-alpha`。

## 验收证据

- 公开仓独立克隆的完整脚本通过，Release 构建零警告、零错误，170 项测试通过。
- Windows 桌面合成实例已核对实际时段问候、常驻日程、鼠标与方向键换日、今天按钮，以及向左拖宽和向右拖窄日程。桌面控制结束时，最小窗口、右栏拖至最窄和键盘调整分隔线仍待复核。
