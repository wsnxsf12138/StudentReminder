# 0.2.4-alpha 版本交接

## 版本定位与目标

- 完成日期：2026-11-11。
- 版本标签：`v0.2.4-alpha`。
- 代码验收提交：标签所指提交。
- 任务 ID / 本轮范围：Moect 导出定时导入，涉及 P2-04、P2-05 和 P3-01、P3-02 的单群文本路径。
- 实际完成与未完成：完成可调导入间隔、授权会话校验、去重和分析队列、DeepSeek 与豆包接口。Moect 快照自动刷新和自动导出尚未接入。

## 使用与复现

- 环境和依赖版本：Windows、.NET 10、WPF、Moect 1.2.8、锁定的 SQLite 依赖。API 分析可选，需要用户自己的服务凭据和可用模型 ID。
- 构建、运行、测试命令：`./scripts/Test-Project.ps1`；`dotnet run --project src/StudentReminder.App --configuration Release --no-build`。
- 用户可操作的功能及示例：主窗口打开「微信定时导入」，选导出根目录和授权群样本。默认 30 分钟，可设置 1～1440 分钟。选择服务并填写模型 ID 与 API Key 后，开始导入即可生成候选事项。 [使用步骤](../moect-watch.md)

## 数据与兼容

- 数据目录、配置、日志与敏感信息边界：应用数据默认 `%LOCALAPPDATA%\StudentReminder`。SQLite 保存消息、设置和分析结果，`secrets/` 保存 DPAPI 加密的 API Key。Moect 导出留在用户选择的本机目录。API 收到已授权会话待分析文字及发送时间。
- schema 版本、升级步骤和兼容性：启动执行新迁移 004 至 v4。新增导出指纹和分析队列，消息入库与排队同事务，保留原消息及同步配置。
- 回退步骤和限制：升级前关闭应用并备份数据目录。回退使用 schema v3 的备份或独立数据目录，新版数据保留在原 v4 数据目录。

- 构建结果：锁定还原与 Release 构建通过，0 警告、0 错误。
- 测试数量、结果与必要命令：`./scripts/Test-Project.ps1` 通过 68 项。覆盖 v3→v4、默认和保存的间隔、重叠去重、其他会话过滤、持久队列及两家 API 的请求和结果格式。
