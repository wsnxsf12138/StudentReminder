- 环境和依赖版本：Windows、.NET 10 SDK、PowerShell 7、WeFlow Rust CLI `6.0.0`、qqflow-server `0.10.0`、Moect `1.2.8`；NuGet 锁定还原。
- 构建、运行、测试命令：`./scripts/Test-Project.ps1`，`dotnet run --project src/StudentReminder.App --configuration Release --no-build`。
- 用户可操作的功能及示例：运行 `./scripts/Prepare-P2Environment.ps1 -Action Check` 查看环境。按服务说明在本机配置数据库和 Token 后，从“消息来源”检查连接、选定会话、单次或后台同步。 [启动与配置](../../tools/services/README.md)

## 数据与兼容

- 数据目录、配置、日志与敏感信息边界：助理默认 `%LOCALAPPDATA%\StudentReminder`，`--data-dir` 可隔离。Rust 配置在 `%LOCALAPPDATA%\StudentReminderSources\WeFlowCli`，QQ 服务目录为 `%LOCALAPPDATA%\qqflow-server`，应用 Token 由当前用户 DPAPI 保存。`artifacts/`、数据库、日志、Token 与真实消息留在本机。
- schema 版本、升级步骤和兼容性：启动时通过新增 003 从 schema v2 升级到 v3，保留来源修订号、会话选择、消息和游标。旧迁移原样保留。来源别名保存已绑定的 Rust 账号哈希，切换适配器后仍保留。
- 回退步骤和限制：升级前关闭应用并复制数据目录，保留数据库及伴随文件。回退时使用升级前备份或单独数据目录运行旧版；升级后新增的记录仍留在 v3 数据目录。
