# 0.6.3-alpha 版本交接

## 版本定位与目标

- 完成日期：2026-11-13。与 `0.6.4-alpha`、`0.6.5-alpha` 一并同步到 [StudentReminder 公开仓库](https://github.com/wsnxsf12138/StudentReminder)，公开源码快照由发行标签 `v0.6.5-alpha` 定位。
- 本轮范围：修复 QqLocal 直读的群聊会话名称显示为 QQ 群号的问题。
- 实际完成：会话列表与消息映射使用真实群名；重新读取会话时回填已入库消息中仍等于群号的旧名称，且不覆盖用户自定义名称。

## 使用与复现

- Windows 10/11、.NET 10 SDK。运行 `dotnet restore StudentReminder.sln --locked-mode` 与 `dotnet test StudentReminder.sln -c Release --no-restore`。
- 用户操作与以往一致：保持 QQ 登录，进入「消息来源 → QqLocal」点「读取会话」。会话列表即显示真实群名，此前已入库的数字群名随会话重新读取回填。

## 数据与兼容

- SQLite 继续使用 schema v8，无迁移、无字段变更。
- 新增读取 `group_info.db` 的 `group_list` / `group_detail_info_ver1` 表：`60001`（群号）、`60007`（群名）数字列。读取为只读快照，不产生写入。
- 历史回填仅在消息的会话名称仍等于群号时执行，用户已改名的会话不受影响。升级前退出旧实例，回退到同为 schema v8 的版本无需迁移。

## 验收证据

- 本机 `dotnet test StudentReminder.sln -c Release --no-restore` 通过，Release 构建 0 警告、0 错误，156 项测试全部通过。
- 新增群名读取（`group_list` 与 `group_detail_info_ver1` 两个表）与历史名称回填回归测试。
- 用本机解密库核对：`group_list` 使用 `60001`（群号）/`60007`（群名），此前代码只查找 `group_name` 等通用列名导致全部回退为群号。
