# 0.6.13-alpha 版本交接

## 版本定位与目标

- 完成日期为 2026-11-14，任务范围为 P4-04 的月历分栏。日历恢复为周一至周日固定七列，拖动分隔线可调整两栏宽度。右侧常驻选中日期的清单，上方按本地时段显示问候。
- 本地标签为 `v0.6.13-alpha`。代码验收提交为 `c86f1ca`（`codex/calendar-seven-columns-0.6.13`）。分支沿用本仓 `v0.6.12-alpha`，远端默认分支为 `fd891f2`。

## 使用与复现

- 使用 Windows 与 .NET 10 SDK，运行 `./scripts/Test-Project.ps1`。用 `dotnet run --project src/StudentReminder.App -c Release --no-build -- --data-dir "$env:TEMP\StudentReminder-calendar-seven-columns"` 启动隔离实例。
- 在首页左右拖动分隔线，查看两栏宽度、固定星期表头、选中日期与右侧清单。

## 数据与兼容

- 常规数据位于 `%LOCALAPPDATA%\StudentReminder`。试用包按解压位置使用 `%LOCALAPPDATA%\StudentReminder-Trial` 下的隔离目录。本轮验证使用现有的合成测试。
- SQLite schema 为 v8。回退前退出应用并备份数据目录，再换回同为 v8 的 `0.6.12-alpha`。
