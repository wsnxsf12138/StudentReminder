# 0.6.13-alpha 版本交接

## 版本定位与目标

- 日期：2026-11-14。任务 P4-04 的月历分栏，承接 0.6.12-alpha 的可拖动分栏。日历恢复为周一至周日固定七列，拖动分隔线可调整月历与右侧清单的宽度，上方按本地时段显示问候。两仓用 `v0.6.13-alpha` 标签定位版本快照。
- 本版一并修复发行打包脚本：脚本自身丢失 UTF-8 标记，且在默认 Windows 终端下把 git 返回的 UTF-8 路径解码为乱码，文件白名单检查因此中止出包。

## 使用与复现

- Windows 10/11、.NET 10 SDK。仓库根目录运行 `./scripts/Test-Project.ps1` 进行锁定还原、Release 构建和测试。
- 隔离启动：`dotnet run --project src/StudentReminder.App -c Release --no-build -- --data-dir "$env:TEMP\StudentReminder-calendar-seven-columns"`，在首页左右拖动分隔线查看两栏宽度、固定星期表头与右侧清单。
- 出包：`./packaging/New-ReleasePackage.ps1 -Version 0.6.13-alpha`；含模型版加 `-IncludeModels -OutputRoot artifacts/release/with-model`，模型取自 `artifacts/local-models`，哈希须与脚本常量一致。 [公开预发行](https://github.com/wsnxsf12138/StudentReminder/releases/tag/v0.6.13-alpha)

## 数据与兼容

- 常规数据位于 `%LOCALAPPDATA%\StudentReminder`，试用包按解压位置使用 `%LOCALAPPDATA%\StudentReminder-Trial` 下的隔离目录。`--data-dir` 可指定独立目录。
- SQLite schema 为 v8，无迁移。退出程序并备份整个数据目录后，可回退到同为 v8 的 0.6.12-alpha。
- 版本资料、测试与发行包仅使用合成标识。对应源码、许可与二进制来自同一个公开提交。
