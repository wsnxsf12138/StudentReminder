# 0.6.2-alpha 版本交接

## 版本定位与目标

- 完成日期为 2026-11-13。公开源码快照由发行标签 `v0.6.2-alpha` 定位。
- P5-01 完成本轮 Windows 回归。P5-04 交付一键清除微信与 QQ 直读缓存、隔离数据目录、离线删除步骤和第三方依赖工程审查。项目采用 GPL-3.0。 [第三方审查](../third-party-audit.md)

## 使用与复现

- Windows 10/11、.NET 10 SDK。运行 `./scripts/Test-Project.ps1` 进行锁定还原、Release 构建与测试。使用 `dotnet run --project src/StudentReminder.App -c Release --no-build -- --data-dir "$env:TEMP\StudentReminder-p5-demo"` 启动隔离实例。
- 打开「设置 → 隐私与数据」。核对显示的路径后，点击「清除微信和 QQ 直读缓存」并确认。助理等待采集和在途分析结束后清理，两种来源分别报告结果。遇到文件占用时，关闭占用者后重试。再次读取会话或同步时可重建缓存。

## 数据与兼容

- SQLite 继续使用 schema v8。默认目录为 `%LOCALAPPDATA%\StudentReminder`，本版本的 `--data-dir` 实例在自己的目录内维护数据库、日志、DPAPI 凭据、两种缓存与临时快照。
- 应用内清理保留消息、事项、授权、入库检查点、API Key 和旧探针的 `exports`。若递归删除中断，可能留下 `wxlocal.clearing` 或 `qqlocal.clearing`，可以再次清理。目录联接、符号链接或检测到嵌套实例库时会拒绝清理相应来源。旧版本留在 Windows 临时目录的孤立快照须先核对归属。
- 升级前退出旧实例并备份助理资料。回退到同为 schema v8 的 v0.6.1-alpha 时先退出，再用备份副本启动旧版。旧版自定义实例仍使用默认直读缓存。回退到 schema v7 的版本须恢复升级到 v8 前的备份。整目录离线删除见 [README](../../README.md#清除缓存与本地资料)。
