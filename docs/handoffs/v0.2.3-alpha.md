# 0.2.3-alpha 版本交接

## 版本定位与目标

- 完成日期：2026-11-11。
- 版本标签：`v0.2.3-alpha`。
- 代码验收提交：标签所指提交。
- 任务 ID / 本轮范围：QQMessageCollector 计划第一阶段的环境检查和 QQMessageTest，关联原计划 P2-03、P2-04。
- 实际完成与未完成：完成独立控制台、Win-x64 自包含发布和合成正向 WebSocket 联调。真实 QQ 采集等待兼容的 Framework 环境。

## 使用与复现

- 环境和依赖版本：Windows x64，开发使用 .NET 10 SDK；已发布的控制台内置 .NET 运行时。真实运行需要已经启用的本机 NapCat OneBot 11 正向 WebSocket。
- 构建、运行、测试命令：`./scripts/Test-Project.ps1`；控制台及发布命令见 [环境验证](../poc-napcat.md)。
- 用户可操作的功能及示例：运行 `QQMessageTest.exe`，本机填端口、测试账号及一个获授权的群或好友，输入 Token。开启正文显示后，在控制台核对发送者、会话类型、时间和正文。按 `Ctrl+C` 停止。

## 数据与兼容

- 数据目录、配置、日志与敏感信息边界：控制台在进程内使用 Token，状态和消息输出在当前终端。默认只显示消息类型及时间，正文需本机选择显示。
- schema 版本、升级步骤和兼容性：测试程序暂无持久化，主应用仍使用 schema v3。
- 回退步骤和限制：退出控制台即可停止接收；可直接启动前一版应用。该测试程序未建立消息数据库。

## 验收证据

- 构建结果：Release 0 警告、0 错误。Windows x64 自包含单文件在本机独立启动，未指定可用的外部 .NET 路径。

- 桌面交互或集成验证：真实本机 WebSocket 上模拟 OneBot 推送。断线前收到授权群消息 1 条，重连后收到授权好友消息 1 条。错误账号、其他会话、自己消息和异常帧被过滤。
