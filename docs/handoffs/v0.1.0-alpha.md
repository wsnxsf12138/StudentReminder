- 六层项目及核心契约；SQLite schema v1、事务、账号隔离、上游 ID/指纹去重、单向撤回标记和冲突证据保留。
- 128 条主样本 / 16 类场景，另附 2 条冲突证据，共 130 条；只记操作类型、计数和异常类型的本地日志；锁定依赖与 Windows CI。

环境：Windows 10/11 x64、.NET 10 SDK；本机实测 SDK 10.0.403。运行：

构建前先关闭运行中的应用实例，防止 Windows 的 DLL 文件锁导致复制失败。

```powershell
dotnet restore StudentReminder.sln --locked-mode
dotnet build StudentReminder.sln --configuration Release --no-restore
dotnet run --project src/StudentReminder.App --configuration Release --no-build
./scripts/Test-Project.ps1
```

首次点击“导入合成样本”应新增 117、重复 7、撤回更新 4；再次点击应新增 0、重复 128。粘贴按输入的发送时间去重，改变该时间代表不同消息。JSON 协议见 `docs/import-format.md`。

## 数据、兼容与回退

- 默认 `%LOCALAPPDATA%\StudentReminder\messages.db` 和 `logs/`；使用 `--data-dir <目录>` 可隔离测试数据。
- SQLite 明文存储消息和证据；当前没有密钥、云端请求、QQ/微信连接或后台采集。运行数据不进入 Git。
- schema 版本 1，只实现空库到 v1；重复初始化不删除数据；高版本库拒绝降级。
- 回退代码时先关闭应用、另行备份自己使用的数据目录，使用 `git switch --detach <旧版本标签>` 检查旧版。应用升级与数据库回退须分别处理，旧应用不能保证读新 schema；不要直接覆盖数据库。
- 当前基线是仅文档的初始化提交，没有可运行的更早应用版本可供回退。
