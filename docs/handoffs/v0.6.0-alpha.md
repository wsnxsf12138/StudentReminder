# 0.6.0-alpha 版本交接

## 版本定位与目标

- 完成日期为 2026-11-13。代码验收提交为 `f1c58c2`，完整快照由 `v0.6.0-alpha` 标签定位。
- 承接 P3-02、P3-03、P3-04、P3-06，新增进程内本地初筛、同会话关联消息、云端精提取、跨消息时间校验和仅日期事项。此次交付为本机 alpha。

## 使用与复现

- Windows 10/11、.NET 10 Desktop Runtime。可运行 `artifacts/v0.6.0-alpha/StudentReminder.App.exe`。开发时运行 `./scripts/Test-Project.ps1` 后，也可用 `dotnet run --project src/StudentReminder.App -c Release --no-build -- --data-dir "$env:TEMP\StudentReminder-hybrid-demo"` 启动隔离实例。
- 「AI 分析 → 本地初筛」可测试和选择 GGUF。试用目录的 `Models` 随附 2B Q4_K_M，程序会识别。4B GGUF 可手动选择。勾选并保存后，到「本地直读自动分析」选择授权会话再启动。
- 「历史消息」的逐条预览显示发送时间和时区。勾选同一会话的 2～4 条消息，点「联合分析」并确认脱敏出站预览。至少一条应仍可提取，已分析的消息可作上下文。
- 本地推理为 LLamaSharp 0.30.0 及 CPU 后端，由应用直接加载，无需另外运行模型服务。推理使用 4,096 Token 的上下文，模型包可将 GGUF 放在程序同级的 `Models` 目录。 [LLamaSharp](https://github.com/SciSharp/LLamaSharp/releases)

## 数据与兼容

- 默认数据目录为 `%LOCALAPPDATA%\StudentReminder`。启动前备份 v7 数据目录。schema v8 为同会话上下文查询增加索引，并允许候选和事件版本记录仅日期字段。回退至 v0.5.1-alpha 前需恢复 v7 备份。
- 本地初筛只读取授权会话中自动分析开启后发送且入库的消息，最多查看过去 20 分钟内的 5 条前文。云端每次最多收到当前消息加 3 条脱敏片段、各自发送时间、时区和当次临时发言代号。云端调用保留原有预算和限流。本地模型无法运行时混合分析暂停。
- 程序从模型指定的消息逐字校验时间引用，并按含日期的那条消息的发送时间解析。仅有日期的事项可显示在「今日」，补录具体时刻后才会排定时提醒。

## 验收证据

- 独立 Git 工作树锁定还原和 Release 构建 0 警告、0 错误，`./scripts/Test-Project.ps1` 的 137 项测试全通过。新增测试覆盖 v7→v8、联合出站脱敏、跨午夜日期锚点、两条证据、撤回拦截、仅日期及本地误筛后的规则兜底。
