# 0.5.1-alpha 版本交接

## 版本定位与目标

- 完成日期为 2026-11-12。完整版本快照由 `v0.5.1-alpha` 标签定位。
- 本轮追加 AI 模型配置交互，承接 P3-01 的服务商配置和 P4-03 的摘要润色。DeepSeek 和豆包共用「模型设置」标签页。用户可用 API Key 获取模型列表、搜索并选中 ID，也可以手填。

## 使用与复现

- Windows 10/11、.NET 10 SDK、WPF。运行 `./scripts/Test-Project.ps1`，用 `dotnet run --project src/StudentReminder.App --configuration Release --no-build -- --data-dir "$env:TEMP\StudentReminder-model-demo"` 启动隔离实例。
- 打开「AI 分析 → 模型设置」，选择服务商，输入 API Key 或留空沿用已保存密钥。点「获取模型列表」，搜索模型后点击列表项，或直接编辑「当前模型 ID」。豆包支持手填 `ep-…` 接入点。点「测试连接」验证模型推理和 JSON 响应。
- 模型列表采用两个服务商的官方接口。 [DeepSeek 模型列表](https://api-docs.deepseek.com/zh-cn/api/list-models/) · [火山方舟 Models API](https://console.volcengine.com/ark/region:cn-beijing/docs/models-api)

## 数据与兼容

- SQLite schema 仍为 v7，已有模型 ID 和 DPAPI 密钥可继续使用。默认数据目录为 `%LOCALAPPDATA%\StudentReminder`。调试可用 `--data-dir` 隔离数据、日志和凭据。
- 点击获取列表会向所选服务商发送鉴权请求，输入内容和列表结果留在当前窗口。保存配置和测试连接沿用已有的本地存储流程。
- 退出 0.5.1-alpha 后可用 0.5.0-alpha 打开同一 schema v7 数据目录。模型需仍可由服务商调用。
