# 0.6.10-alpha 版本交接

## 版本定位与目标

- 完成日期为 2026-11-14。任务为计划书 **P4-04** 的首页事项展示与证据追溯。
- 首页默认打开「事项日历」。月历按周一到周日显示六周，可翻月、选相邻月份日期或回到今天。每格显示两条预览，超出的安排显示数量。右侧显示当天完整清单，可点击标题查看事项详情及来源证据。
- 已确认且进行中或已完成的事项按开始和截止分别列出。精确时间按本机时区落到日期，只有日期的事项显示「时间待定」。多日事项在起止日分别显示。
- 「消息导入」保留合成样本、手动粘贴、JSON 导入和消息证据。修复跨月时日期格丢失键盘焦点的问题。方向键左右移一天、上下移一周。
- 本地完整快照标签为 `v0.6.10-alpha`。代码验收提交为 `9324deb`（`codex/calendar-0.6.10`）。本分支从远端 `main` 的 `fd891f2` 起步，纳入独立克隆已有的 0.6.9-alpha 图标改动 `071adac`。

## 使用与复现

使用 Windows 10/11 与 [global.json](../../global.json) 指定的 .NET 10 SDK。在仓库根目录运行以下命令。

```powershell
./scripts/Test-Project.ps1
$calendarData = Join-Path $env:TEMP ('StudentReminder-calendar-' + [guid]::NewGuid().ToString('N'))
dotnet run --project src/StudentReminder.App -c Release --no-build -- --data-dir $calendarData
```

1. 检查首开是否默认选中今天并显示无安排。操作上一月、下一月、前后月日期及「回到今天」，用方向键跨月检查焦点。
2. 在「消息导入」两次点击「导入合成样本」。第一次应新增 117 条、重复 7 条、撤回更新 4 条，第二次新增 0 条、重复 128 条。选一条消息查看证据。
3. 在隔离库准备合成候选后，用「事项」确认和改期，检查同日的两个时间节点、日期精度、完成状态及月历刷新。点击右侧标题核对是否打开对应事项及证据。样本按钮只导入消息，月历验收需另外准备已确认的事项。

## 数据与兼容

- 常规数据目录为 `%LOCALAPPDATA%\StudentReminder`，试用包按解压位置在 `%LOCALAPPDATA%\StudentReminder-Trial` 下隔离。`--data-dir` 隔离数据库、配置、日志、凭据和直读缓存。本轮桌面验收使用独立目录与合成数据。
- SQLite 沿用 schema v8，本次无迁移。回退前退出应用并备份整个数据目录，再换回同为 schema v8 的 0.6.9-alpha。
