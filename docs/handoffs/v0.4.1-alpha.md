# 0.4.1-alpha 版本交接

## 版本定位与目标

- 完成日期为 2026-11-12。用 `git rev-parse v0.4.1-alpha^{commit}` 定位验收提交。
- 范围为 P2-01、P2-06 的桌面入口修复，是 P3 微信自动分析的采集前置。WxLocal 发现账号并读取会话后，仓库曾只允许 WeFlow Rust CLI 保存账号绑定，导致会话列表无法载入。
- 账号绑定和会话保存已通过合成验收。一次检测、读取和监听使用同一发现的账号目录，已绑定来源会拒绝其他账号。

## 使用与复现

- Windows 10/11、.NET 10、WPF。验收使用 .NET SDK 10.0.403。
- 运行 `./scripts/Test-Project.ps1` 检查，或在本机运行 `artifacts/v0.4.1-alpha/StudentReminder.App.exe`。从标签重建后可用 `dotnet run --project src/StudentReminder.App --configuration Release --no-build` 启动。
- 微信保持登录。在应用「消息来源」选择已有 WxLocal 配置，或新建配置、填写自定别名并保存。点「读取会话」，勾选授权会话，再点「保存会话选择并暂停」及「开始后台同步」。可先点「同步一次」查看新增数量。 [操作步骤](../../README.md#来源配置与同步)

## 数据与兼容

- 默认数据目录为 `%LOCALAPPDATA%\StudentReminder`，沿用原数据库和来源配置。SQLite schema 为 v5，本版无迁移。账号绑定保存为本地哈希。
- 回退时关闭应用并换回 0.4.0-alpha，可沿用 v5 数据目录。升级或回退前可备份应用数据目录。

## 验收证据

- 用新增回归测试复现旧版「来源配置已变化」错误。修复后确认能保存 WxLocal 账号与会话、重复读取保留勾选、绑定其他账号时拒绝写入。
- 将基线与本版修改放在隔离目录运行 `./scripts/Test-Project.ps1`。锁定还原成功，Release 构建 0 警告、0 错误，131 项测试通过。
- WPF 合成验收走通保存 WxLocal 配置、检查连接、读取会话、保存授权、同步一次、后台增量入库和暂停。模拟私聊保持未选中。
- 在本机以只读环境检查确认可发现一个微信账号目录。真实会话读取、实际微信新消息入库和云 API 验收待做。远端 CI 未运行。

## 已知问题与下一步

- 账号发现结果在应用里表现为会话列表。多账号环境仍按本地数据库最近写入时间选择目录。切换账号时应先暂停，再用新别名创建来源。
- 下一步在真实微信中选一个授权测试会话，先「同步一次」核对入库，再启用后台同步接收测试新消息。需要 AI 时在「AI 分析」单独开启。 [WxLocal 接入说明](../wx-local-reader.md)
