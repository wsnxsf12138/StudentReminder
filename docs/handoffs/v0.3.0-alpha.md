- 完成日期：2026-11-11。

## 使用与复现

- 环境和依赖版本：Windows 10/11、.NET 10、WPF；新增 `StudentReminder.WxLocal.Adapter`（`net10.0-windows`，无新增 NuGet 依赖，复用 `Microsoft.Data.Sqlite` / `ZstdSharp.Port` / `System.Text.Encoding.CodePages`）。
- 构建、运行、测试命令：`./scripts/Test-Project.ps1`（还原时若本机漏洞数据源不可达，可加 `-p:NuGetAudit=false`）；`dotnet run --project src/StudentReminder.App --configuration Release --no-build`。
- 用户可操作的功能及示例：打开「消息来源 → 新建配置」，适配器选「WxLocal（微信直读）」，填本地账号别名、兜底轮询间隔与首次回溯天数，勾选「启用实时文件监听（推荐）」保存；「读取会话」列出本机微信会话，勾选授权群后「开始后台同步」。微信需保持登录，密钥提取建议以管理员身份运行应用。

## 数据与兼容

- 数据目录、配置、日志与敏感信息边界：应用数据 `%LOCALAPPDATA%\StudentReminder`；WxLocal 明文缓存（解密影子库 + `keys.json` + `wal-cursor.json`）位于 `%LOCALAPPDATA%\StudentReminder\wxlocal\<wxid>\`，视同聊天明文，不进同步盘、不入日志。
- schema 版本、升级步骤和兼容性：未新增数据库迁移；复用现有 `sync_cursors`（消息游标）与幂等去重链路。`SourceDefinition` 适配器白名单新增 `wxlocal`，`Platform` 映射为 wechat，`SupportsPush` 为 true（用于文件监听）。
- 回退步骤和限制（含数据备份要求）：升级前关闭应用并备份数据目录；回退到 v0.2.4 可用同一数据目录（schema 不变）。删除 `wxlocal` 缓存目录可强制下次全量重刷，不影响微信原始数据库。
