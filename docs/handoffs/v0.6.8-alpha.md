# 0.6.8-alpha 版本交接

## 版本定位与目标

- 日期：2026-11-13。任务 ISSUE-02，承接 P2-03 的 QqLocal 会话发现。两仓用 `v0.6.8-alpha` 标签定位版本快照。
- 好友备注或昵称优先，公众号资料及最近会话标题提供补充显示名。QQ NT 的 `profile_info_public_account` 按会话 UID 识别公众号，界面加上「QQ 公众号」标识。缺少名称时采用私聊消息的对端号码；号码缺失或记录互相冲突时使用带短后缀的占位名称。

## 使用与复现

- Windows 10/11、.NET 10 SDK。仓库根目录运行 `./scripts/Test-Project.ps1` 进行锁定还原、Release 构建和测试。
- 升级后保持 QQ 登录，进入「消息来源 → QqLocal → 读取会话」。列表中的三条旧记录可按公众号标题或号码识别。历史消息中仍使用原 UID 作为会话名称的记录随读取回填。
- 公开 Win x64 ZIP 完整解压后启动 `StudentReminder.App.exe`。含模型版自带本地初筛所用的 GGUF。 [公开预发行](https://github.com/wsnxsf12138/StudentReminder/releases/tag/v0.6.8-alpha)

## 数据与兼容

- 常规实例数据位于 `%LOCALAPPDATA%\StudentReminder`，试用包默认使用 `%LOCALAPPDATA%\StudentReminder-Trial` 下按解压位置隔离的目录。`--data-dir` 可指定独立目录。
- 会话 ID、群聊和私聊的同步协议、授权选择及游标沿用现有数据。SQLite schema v8，无迁移。退出程序并备份整个数据目录后可使用同为 schema v8 的 0.6.7-alpha 回退。
- 版本资料、测试与发行包仅使用合成标识。对应源码、许可与二进制来自同一个公开提交。
