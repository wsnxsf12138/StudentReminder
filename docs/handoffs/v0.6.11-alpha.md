# 0.6.11-alpha 版本交接

## 版本定位与目标

- 完成日期为 2026-11-14。范围为 P4-04 的首页月历改版，以及首页和 AI 分析窗口的导航、模型操作图标。
- 月历使用全宽网格，按月份显示四到六周。日期和事项标签居中，开始、截止、已完成分别使用浅绿、浅蓝和暖灰。日期格显示一条预览，其余用 `+N` 表示。点日期或「当天安排」可打开可滚动的清单。
- 首页入口、月历翻页、AI 分析的四个页签及模型设置按钮复用 WPF 线性矢量图标。EXE 和托盘沿用既有图标。
- 本地版本标签为 `v0.6.11-alpha`。验收代码提交为 `24896ef`（`codex/calendar-ui-0.6.11`）。本分支基于远端 `main` 的 `fd891f2`，纳入本仓既有的 `v0.6.10-alpha`。

## 使用与复现

- 在 Windows 与 .NET 10 SDK 下运行 `./scripts/Test-Project.ps1`。用 `dotnet run --project src/StudentReminder.App -c Release --no-build -- --data-dir "$env:TEMP\StudentReminder-calendar-layout"` 启动隔离实例。
- 在「事项日历」翻月、点击日期或「当天安排」，可通过事项标题打开证据和详情。日期格获得焦点后，左右键移动一天、上下键移动一周，Enter 或空格打开清单，Esc 关闭。
- 在「AI 分析」切换模型设置、本地初筛、本地直读自动分析或历史消息，检查页签图标和选中状态。

## 数据与兼容

- 常规数据目录为 `%LOCALAPPDATA%\StudentReminder`。试用包按位置使用 `%LOCALAPPDATA%\StudentReminder-Trial` 下的独立数据目录。验收仅使用隔离目录中的合成数据。
- SQLite schema 继续使用 v8。回退时先关闭应用并备份整个数据目录，再换回同为 v8 的 `0.6.10-alpha`。
